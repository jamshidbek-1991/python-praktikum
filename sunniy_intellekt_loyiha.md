# Sun'iy Intellekt Loyihasi - Teachable Machine

Google Teachable Machine platformasi yordamida (no-code) yaratilgan rasm tanish modeli.

## Loyiha haqida
Model kamera orqali 4 xil obyektni real vaqtda taniydi:
- 🍎 Olma
- 🍼 Baqlashka
- 👤 Jamshidbek (yuz tanish)
- 📱 Telefon

## Ishlatilgan texnologiya
- Platforma: Google Teachable Machine (teachablemachine.withgoogle.com)
- Model turi: Image Project (Standard image model)
- Kod yozilmagan - to'liq vizual/no-code yondashuv

## Sinab ko'rish
Quyidagi havola orqali brauzerda (kompyuter yoki telefon) sinab ko'rish mumkin:

https://teachablemachine.withgoogle.com/models/ENVUsYdQY/

## Qanday ishlaydi
1. Havolani oching
2. Kameraga ruxsat bering
3. Kamerani olma, butilka, telefon yoki o'zingizga qarating
4. Model real vaqtda qaysi obyekt ekanini foizda ko'rsatadi

## Mobil qurilmada ishlatish
Havolani telefon brauzerida ochib, "Bosh ekranga qo'shish" orqali ilova ko'rinishida ham ishlatish mumkin (Android - Chrome, iPhone - Safari).
